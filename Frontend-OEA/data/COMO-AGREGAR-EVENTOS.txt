CÓMO AGREGAR UN EVENTO NUEVO A LA PÁGINA
==========================================

CAPACITACIÓN PARA LA PERSONA ENCARGADA

La página pública de eventos es:

  eventos.html

La página para administrar eventos es:

  admin-eventos.html

No se editan eventos desde eventos.html. Entra siempre a admin-eventos.html
usando Live Server:

  http://127.0.0.1:5500/Frontend-OEA/admin-eventos.html

Desde ese panel puedes:

- Crear un evento nuevo.
- Pulsar "Editar" para modificar un evento existente.
- Pulsar "Eliminar" para quitar un evento del borrador.
- Descargar el archivo actualizado con "Descargar eventos.json".

Después de descargar el archivo, reemplaza el archivo original en:

  Frontend-OEA/data/eventos.json

Finalmente, recarga eventos.html para comprobar el resultado. El panel local
no modifica archivos del proyecto automáticamente por seguridad del navegador.

No necesitas saber programar. Solo tienes que editar el archivo:

    data/eventos.json

Ábrelo con el Bloc de notas (clic derecho → Abrir con → Bloc de notas)
o con cualquier editor de texto simple.

Vas a ver una lista de eventos, cada uno con esta forma:

    {
      "title": "Feria de Ciencias 2026",
      "date": "2026-10-14",
      "description": "Descripción corta que aparece en la tarjeta.",
      "details": "Descripción más completa que aparece al pulsar Ver evento.",
      "imageUrl": "img/fotos-colegio/feria-ciencias.jpg",
      "imageUrls": [
        "img/fotos-colegio/feria-ciencias.jpg",
        "img/fotos-colegio/feria-ciencias-2.jpg"
      ]
    },

PARA AGREGAR UN EVENTO NUEVO:

1. Copia uno de los bloques completos (desde la llave { hasta la llave
   } incluyendo la coma final).
2. Pégalo justo antes del cierre de la lista (el corchete final ] ).
3. Cambia los textos:
   - "title": el nombre del evento
   - "date": la fecha en formato AAAA-MM-DD (año-mes-día)
   - "description": una descripción corta
   - "details": texto opcional que aparece al pulsar "Ver evento".
   - Desde admin-eventos.html selecciona la foto principal y las fotos
     adicionales directamente desde tu computadora.
   - El panel guardará las imágenes dentro del archivo descargado. No
     necesitas escribir rutas ni cambiar nombres de archivos.
   - Si no seleccionas una foto, se usará el escudo de la institución.
4. Guarda el archivo (Ctrl + S). Mantenlo como texto plano (.json), no
   lo guardes como .txt ni como Word.
5. Abre la página usando un servidor local y recarga Eventos. No abras
  eventos.html con doble clic, porque el navegador puede bloquear la
  lectura de data/eventos.json por seguridad.

PARA PROBARLO EN VS CODE:

1. Instala la extensión "Live Server".
2. Haz clic derecho en Frontend-OEA/eventos.html.
3. Elige "Open with Live Server".
4. Guarda eventos.json y recarga la página.

PARA QUITAR UN EVENTO:

Simplemente borra su bloque completo (desde la llave { hasta la llave
} con su coma).

IMPORTANTE:

- Cada bloque de evento va separado por una coma, EXCEPTO el último de
  la lista, que no lleva coma al final.
- Si guardas el archivo y la página deja de mostrar eventos, revisa que
  no haya quedado una coma de más o una llave sin cerrar. La forma más
  fácil de verificar esto es copiar todo el contenido del archivo y
  pegarlo en https://jsonlint.com para que te diga si hay algún error.
- El último evento no lleva coma después de su llave final.
- Las fechas deben escribirse como AAAA-MM-DD, por ejemplo 2026-10-14.

NOTA TÉCNICA (para quien dé mantenimiento más adelante):
Este archivo es un reemplazo temporal y manual de una base de datos.
Cuando el backend (NestJS + Prisma + Supabase) esté listo, solo hay que
cambiar la línea "apiUrl" en js/main.js para que apunte al endpoint real
de la API, y todo lo demás (la tarjeta, el formato de fecha, los estados
de carga) sigue funcionando igual sin tocar el HTML ni el CSS.
